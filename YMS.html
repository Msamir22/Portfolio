Yard Management System

Capstone Logistics 2021

Enterprise yard-management solution with real-time RFID/trailer tracking, check-in/out workflows, dock coordination, and live yard visibility integrated with Managed Receiving.

Project Overview

The platform gives warehouse teams live visibility into trailers moving through the yard and connects those workflows with Managed Receiving. The UI supports operational tracking, check-in/out activity, dock coordination, and data-heavy views where responsiveness and clarity are critical.

My Role

  • Build reusable Angular components for operational and data-heavy views
  • Implement reactive real-time tracking flows with RxJS
  • Build and refine interactive yard-map experiences
  • Integrate Yard Management workflows with Managed Receiving
  • Improve responsiveness and performance for large operational datasets
  • Contribute to technical decisions and reusable front-end patterns shared across enterprise workflows

Technologies

Angular RxJS Angular Material TypeScript Jasmine REST API
