Monyvi

Personal Product 2026 - Present GitHub Repository

An offline-first personal finance companion for the Egyptian market, designed to reduce manual financial entry through voice, SMS automation, and reliable local-first data flows.

Product Scope

Monyvi tracks cash, bank accounts, digital wallets, transactions, budgets, recurring payments, multi-currency balances, precious-metal holdings, and live market rates. The product is built around the needs of Egyptian users and aims to make everyday financial tracking substantially less manual.

Architecture

  • React Native / Expo mobile application in an Nx monorepo
  • WatermelonDB as the user-facing local source of truth with background Supabase synchronization
  • Supabase Auth, PostgreSQL, RLS, Edge Functions, and SQL migrations
  • Shared financial calculations and parsers isolated into reusable logic packages
  • CI/CD and automated verification through GitHub Actions

AI & Automation

  • DeepSeek V4 Flash through DeepInfra for structured SMS-to-transaction parsing
  • Gemini 2.5 Flash-Lite for multilingual voice/audio-to- transaction parsing
  • Structured model outputs, schema validation, retry/failure handling, provider configuration, and model evaluation
  • Arabic, English, and mixed-language financial input support

Agentic Engineering

I designed repository-level AI workflows and reusable skills for architecture, planning, TDD, code review, PR follow-up, UI/mockup implementation, session handoffs, and multi-agent task delegation. The workflow emphasizes scoped ownership, explicit approval boundaries, deterministic verification, and human review rather than treating AI output as automatically correct.

Technologies

React Native Expo TypeScript WatermelonDB Supabase PostgreSQL Nx NativeWind DeepSeek Gemini DeepInfra GitHub Actions Maestro
